# LAW301 + LAW302 Lessons

One-page study site: LAW302 Conflict of Laws (pre-writes 00, J1–J7, C1–C3) and LAW301 Legal Theory (exam-sheet archetypes 2–12), with 83 flowcharts and 630 multiple-choice questions.

Open the site, then press `?` for the keyboard shortcuts (`/` search, `S` side by side, `[` `]` lessons).

**Saving progress.** Answers are kept in your browser. Press `G` (or the Save button) and paste a GitHub token with only the `gist` scope to save them to a secret gist in your own account, so they follow you to any computer. The token is stored only in your browser and sent only to api.github.com. A backup file option needs no account.

**Comments while you read.** Select any text and press **Comment** (or Ctrl/⌘+Shift+M). The text is highlighted and your comment appears on the right, beside it, with replies, edit, delete and resolve. The 💬 Comments button lists every comment on every page. Comments are kept in your browser and, if you've connected a token with Save, in a secret gist on your GitHub account. They are never stored in the lesson files, so uploading new course material doesn't remove them. The `comments/` folder and the "Keep comments attached" GitHub Action keep the feature on every page after each upload.
